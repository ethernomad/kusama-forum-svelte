## Package manager preference

- **You must always use `pnpm` instead of `npm`** (including scripts) whenever running package-manager commands.

## Commit policy

- **Never perform a commit unless explicitly told to do so.**
- When committing, do not ask for the commit message; generate it automatically.

## Codebase modification policy

- When modifying the codebase, always try to refactor it to increase overall code quality.
- When modifying the codebase, always keep the ARCHITECTURE.md file up to date.
